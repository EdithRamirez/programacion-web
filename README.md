# 💻 Programación Web — 2027-1

Repositorio académico para las clases de **Programación Web** de **7.º cuatrimestre** de la **Licenciatura en Sistemas Computacionales** en **Universidad Mexicana**.

## 📘 Objetivo

Este repositorio reúne los ejercicios, prácticas y materiales desarrollados durante el curso, con el propósito de dar seguimiento al aprendizaje de programación web y conservar una evidencia organizada del trabajo realizado durante el cuatrimestre.

## 🛠️ Tecnologías y herramientas

Durante el curso se trabajará principalmente con:

- 🌐 **HTML5** — estructura básica de páginas web.
- 🎨 **CSS3** — estilos y presentación visual.
- 🐘 **PHP** — programación del lado del servidor.
- 🧰 **XAMPP** — entorno local para ejecutar Apache y PHP.
- 📝 **Visual Studio Code** — editor de código utilizado durante las prácticas.
- 🗂️ **Git y GitHub** — control de versiones y respaldo de los ejercicios del curso.

## 📂 Organización del repositorio

Los materiales se organizarán por semanas para facilitar su consulta y seguimiento.

```text
programacion-web/
├── semana-01/
├── semana-02/
├── semana-03/
└── ...
```

Cada carpeta podrá contener ejercicios, prácticas, archivos de apoyo y evidencias correspondientes a los temas revisados en clase.
