# PHP + HTML

## Descripción

Integrar **PHP con HTML** para comenzar a generar contenido dinámico dentro de una página web.

## Instrucciones

- Crea la carpeta `semana-03/practica-01/`.
- Agrega los archivos HTML y CSS proporcionados para la práctica.
- Cambia el archivo `index.html` a `index.php`.
- Copia y completa el código PHP mostrado durante la clase.
- Comprueba que la página se visualiza correctamente desde localhost:

```text
http://localhost/semana-03/practica-01/
```

## Tecnologías utilizadas

- HTML5
- CSS3
- PHP
- XAMPP
- Visual Studio Code

## Estructura de archivos

```text
semana-03/
└── practica-01/
    ├── index.php
    └── css/
        └── style.css
```
