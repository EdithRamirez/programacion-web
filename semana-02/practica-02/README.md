# Datos de un alumno

## Descripción

Crear un script en **PHP** para almacenar y mostrar información de un alumno utilizando variables, `echo`, `print` y comentarios.

## Instrucciones

- Crea una variable para almacenar el nombre.
- Crea una variable para almacenar la edad.
- Crea una variable para almacenar el promedio.
- Muestra los valores utilizando `echo`.
- Agrega comentarios para indicar qué hace cada parte principal del código.
- Crea una variable que almacene el resultado de `print` y muestra su valor para comprobar qué devuelve.
- Comprueba el resultado desde localhost.

## Tecnologías utilizadas

- PHP
- XAMPP
- Visual Studio Code
