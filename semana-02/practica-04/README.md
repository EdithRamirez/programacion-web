# Información de una película

## Descripción

Crear y ampliar un script en **PHP** para almacenar, mostrar y procesar información de una película utilizando variables, tipos de datos, concatenación, condicionales y ciclos.

## Instrucciones

- Crea variables para almacenar el nombre, género, año de estreno y duración de una película.
- Utiliza una variable de tipo `bool` llamada `enCartelera` para indicar si la película se encuentra actualmente en cartelera.
- Agrega comentarios para indicar qué hace cada parte principal del código.
- Muestra los datos principales utilizando `echo`.
- Utiliza concatenación para mostrar la información de la película en una oración.
- Utiliza una condición para mostrar si la película está o no en cartelera.
- Crea una variable llamada `calificacion` con un valor entre 1 y 5.
- Muestra siempre cinco estrellas; utiliza la calificación para determinar cuántas se muestran llenas y cuántas vacías.
- Crea una variable llamada `boletosDisponibles` y muestra la cantidad disponible hasta llegar a 0.
- Cuando no queden boletos, muestra el mensaje correspondiente.
- Si la película no está en cartelera, indica que no hay boletos disponibles.
- Comprueba el resultado desde localhost.

## Tecnologías utilizadas
