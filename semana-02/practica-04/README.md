# Información de una película

## Descripción

Crear un script en **PHP** para almacenar y mostrar información de una película utilizando distintos tipos de datos y concatenación.

## Instrucciones

- Crea una variable para almacenar el nombre de una película.
- Crea una variable para almacenar el género.
- Crea una variable para almacenar el año de estreno.
- Crea una variable para almacenar la duración en minutos.
- Crea una variable de tipo `bool` para indicar si actualmente está en cartelera. Solo declárala; su uso se retomará en futuras clases.
- Agrega comentarios para indicar qué hace cada parte principal del código.
- Muestra los datos principales utilizando `echo`.
- Utiliza concatenación para mostrar la información de la película en una oración.
- Comprueba el resultado desde localhost.

## Tecnologías utilizadas

- PHP
- XAMPP
- Visual Studio Code
