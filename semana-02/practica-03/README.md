# Concatenación de datos

## Descripción

Crear un script en **PHP** para combinar texto y valores almacenados en variables utilizando el operador de concatenación `.`.

## Instrucciones

- Crea una variable para almacenar el nombre.
- Crea una variable para almacenar el apellido.
- Crea una variable para almacenar la edad.
- Crea una variable para almacenar el signo zodiacal.
- Muestra los datos utilizando `echo`.
- Utiliza el operador punto (`.`) para concatenar texto y variables.
- Construye una oración que muestre todos los datos en una sola salida.
- Comprueba el resultado desde localhost.

## Tecnologías utilizadas

- PHP
- XAMPP
- Visual Studio Code
