# PHP Básico

## Descripción

Crear la estructura inicial de trabajo y comenzar a desarrollar ejercicios utilizando **PHP** en un entorno local.

## Instrucciones

- Crea la carpeta `semana-02/practica-01/`.
- Crea un archivo `index.php`.
- Copia y completa el código PHP mostrado durante la clase.
- Comprueba que la página se visualiza correctamente desde localhost:

```text
http://localhost/semana-02/practica-01/
```

## Tecnologías utilizadas

- PHP
- XAMPP
- Visual Studio Code

## Estructura de archivos

```text
semana-02/
└── practica-01/
    └── index.php
```
