# Operadores, condicionales y ciclos

## Descripción

Continuar desarrollando ejercicios utilizando **PHP** para trabajar con operadores, estructuras condicionales y ciclos.

## Instrucciones

- Crea la carpeta `semana-02/practica-05/`.
- Crea un archivo `index.php`.
- Copia y completa el código PHP mostrado durante la clase.
- Comprueba el resultado desde localhost.

## Tecnologías utilizadas

- PHP
- XAMPP
- Visual Studio Code
