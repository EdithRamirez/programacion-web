# Formularios: Método GET y POST

## Descripción

Integra **PHP con HTML** para enviar y recibir información mediante formularios utilizando los métodos **GET y POST**.

## Instrucciones

- Utiliza los archivos HTML y CSS proporcionados.
- Renombra los archivos `.html` como `.php` cuando se indique durante la clase.
- Configura los atributos `action`, `method` y `name` de los formularios.
- Utiliza botones de tipo `submit` para realizar el envío.
- Recibe los datos mediante `$_GET` y `$_POST`.
- Utiliza `isset()` para comprobar si los datos fueron enviados antes de utilizarlos.
- Muestra de manera dinámica la información recibida.

## Tecnologías utilizadas

- HTML5
- CSS3
- PHP
- XAMPP
- Visual Studio Code
