# Campus Web — Parcial 02

## Descripción

A partir de la **Semana 07**, Campus Web será el proyecto base de trabajo del segundo parcial.

Las siguientes prácticas se desarrollarán sobre esta misma aplicación, incorporando nuevos temas de manera progresiva. Ya no será necesario crear una carpeta diferente por semana para este proyecto.

## Estructura

```text
campus-web/
├── index.php
├── acceso.php
├── panel.php
├── includes/
│   ├── funciones.php
│   ├── header.php
│   └── footer.php
└── css/
    └── style.css
```

## Progreso esperado

### Semana 07 — Cookies y sesiones

- Uso de cookies para conservar información en el navegador.
- Uso de sesiones para mantener datos entre diferentes páginas.
- Aplicación con arreglos, sin base de datos.

### Semana 08 — Introducción a MySQL

- Transición de datos temporales a una base de datos.
- Creación de la base y tablas necesarias.
- Conexión de PHP con MySQL mediante `mysqli`.

### Semana 09 — Consulta de datos

- Consultas `SELECT`.
- Recuperación de registros desde PHP.
- Presentación de publicaciones almacenadas en MySQL.

### Semana 10 — Registro de datos

- Envío de formularios hacia MySQL.
- Operaciones `INSERT`.
- Registro de usuarios y publicaciones.
- Introducción a consultas preparadas.

### Semana 11 — CRUD

- Edición de publicaciones.
- Operaciones UPDATE y DELETE.
- Control de los registros que puede administrar cada usuario.

### Semana 12 — Integración

- Relación entre usuarios y publicaciones.
- Autenticación con datos almacenados en MySQL.
- Manejo seguro de contraseñas.
- Sesiones, roles y control de acceso.

## Consideraciones

- Trabaja siempre sobre la misma carpeta `campus-web/`.
- Cada nuevo tema deberá integrarse sin eliminar funcionalidades existentes.
- El proyecto continuará evolucionando conforme avance el parcial.
