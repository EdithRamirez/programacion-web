# Reto con IA

## Descripción

Solicita a una herramienta de IA una página HTML sencilla utilizando un **Framework CSS**.

## Requisitos

La página debe incluir:

- Encabezados y párrafos.
- Navegación.
- Una lista y un enlace.
- Una tabla o formulario.
- Uso de un framework: Bootstrap, Materialize o Foundation.

## Análisis del código

Analiza el código generado por la herramienta de IA.

- Agrega comentarios en las partes principales del código.
- Identifica qué clases o componentes pertenecen al framework utilizado.

## Tecnologías utilizadas

- HTML5
- Framework CSS: Bootstrap, Materialize o Foundation.
- Inteligencia Artificial.
