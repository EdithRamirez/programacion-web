# 📚 Material de apoyo — Programación Web

Esta carpeta reúne **ejemplos, archivos de referencia y recursos complementarios** relacionados con los temas trabajados en la materia de **Programación Web**.

## 📘 Objetivo

El material de esta carpeta tiene como propósito apoyar la comprensión de los temas del curso y servir como referencia durante el desarrollo de las prácticas.

Algunos archivos podrán haber sido utilizados o explicados durante la clase, mientras que otros se incluyen como **material complementario para consulta**.
