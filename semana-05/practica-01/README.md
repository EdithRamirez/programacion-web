# Registro de alumnos: validación

## Descripción

Completa el código HTML y PHP mostrado en clase para validar los datos recibidos mediante un formulario antes de mostrar la información del alumno.

## Instrucciones

- Utiliza los archivos proporcionados como base.
- Renombra `registro.html` como `registro.php` cuando se indique durante la clase.
- Recupera los datos enviados mediante `POST`.
- Valida los campos del formulario antes de mostrar la información.
- Muestra los mensajes de error correspondientes.
- Utiliza `htmlspecialchars()` al mostrar datos recibidos del usuario.
- Comprueba el resultado desde `localhost`.

## Tecnologías utilizadas

- HTML5
- CSS3
- PHP
